Project-2 · Internship

Textbook RAG Engine

A FastAPI system that finds textbook answers by board, subject, class, and question.

Click to read more ↗

FastAPI, Python, Qdrant, Ollama (LLaVA), OpenCV, SentenceTransformers, pdfplumber

  • Automated Multimodal Ingestion: Built a custom PDF parsing pipeline using pdfplumber and OpenCV to dynamically detect, crop, clean, and extract complex figure regions and diagrams from raw textbooks.
  • AI Image Captioning: Integrated Ollama's LLaVA vision model to automatically generate descriptive captions for all extracted diagrams, making visual content fully searchable alongside the text.
  • Metadata-Rich Vector Search: Embedded text and image captions using SentenceTransformers and upserted them into a Qdrant vector database, implementing strict metadata filtering capabilities (by board, class, subject, and academic year).
  • Custom Semantic Scoring Algorithm: Engineered a retrieval ranking system that accurately pairs retrieved text chunks with the most relevant diagrams using a weighted combination of cosine similarity, keyword matching, and page-proximity bonuses.
  • High-Performance REST API: Exposed the complete ingestion and retrieval pipelines via FastAPI endpoints, delivering strict, context-grounded LLM responses directly mapped to source files, page numbers, and image URLs.

Project-3 · Computer Vision

Newspaper Layout Detection

A YOLOv10 pipeline for detecting elements in dense Indian newspaper pages.

Click to read more ↗

Python, YOLOv10, Computer Vision (OpenCV), Web Automation, Data Engineering

  • Large-Scale Web Automation: Engineered automated scripts to continuously scrape and download regional e-papers across multiple independent web sources, creating a steady data ingestion pipeline.
  • Custom Data Pre-Processing: Designed and implemented a custom pre-processing pipeline utilizing Logical Entity Grouping techniques. This crucial step organized messy, unstructured e-paper data into logical blocks before feeding it to the model, drastically improving detection accuracy.
